OneDesk

一个人掌控投影片、音乐和投影输出 · One person runs slides, music and the projector

Windows

装在接投影机、运行 PowerPoint 的那台电脑上。
Install on the PC that runs PowerPoint and the projector.

Download for Windows
  • Windows 10 / 11 · PowerPoint 2016 or Microsoft 365 · Spotify app (optional, for music)
  • 第一次打开时如出现“Windows 已保护你的电脑”：点“更多信息 → 仍要运行”（安装程序没有付费的代码签名）。
    If Windows shows "Windows protected your PC": More info → Run anyway (the installer is not code-signed).
  • 双击后没反应或提示无法访问：防毒软件在检查新文件，等几分钟再双击。
    Nothing happens, or "can't access": antivirus is still checking the new file; try again in a few minutes.
  • 已经装了旧版：直接安装即可升级，设置会保留。
    Already installed: just install over it; settings are kept.

Mac

测试版 · Test version

功能和 Windows 版基本相同，但还没有和真正的 PowerPoint 一起测试过，正式使用前请先试一次。
Nearly the same features as on Windows, but not yet tested with PowerPoint on a real Mac: try it before an event.

Apple silicon (M1 and later) Intel Mac
  • 第一次打开：在“应用程序”里按住 Control 点 OneDesk → 打开（没有 Apple 签名）。如提示“已损坏”，在“终端”执行 xattr -cr /Applications/OneDesk.app。
    First start: Control-click OneDesk in Applications → Open (no Apple signature). If it says "damaged", run xattr -cr /Applications/OneDesk.app in Terminal.
  • 投影画面实时截取需要 macOS 14（Sonoma）以上，第一次用时要允许“屏幕录制”。
    The live projector view needs macOS 14 (Sonoma) or later and the Screen Recording permission.
  • 和 Windows 不同：投影模式只有同步和延伸（只用投影机时合上盖子）；没有 OneDesk Wi-Fi，改用手机热点；不需要“加速”。
    Different from Windows: Duplicate and Extend only (close the lid for the projector only); no OneDesk Wi-Fi, use the phone's hotspot; no speed-up needed.

Phone · tablet

不用下载 · No download

手机和平板是遥控器，用网页打开，不用安装。
Phones and tablets are the remote, in the browser; nothing to install.

  1. 在电脑的 OneDesk 点 Remote，用手机相机扫二维码。
    On the PC, click Remote in OneDesk and scan the code with the phone's camera.
  2. 再选“加到主屏幕”，以后像 App 一样从图标打开。
    Then "Add to Home Screen": it opens like an app from then on.

没有 Wi-Fi 时：OneDesk 可以开自己的 Wi-Fi（iPhone 和 Android），或用蓝牙（Android）。
No Wi-Fi: OneDesk can open its own Wi-Fi (iPhone and Android), or use Bluetooth (Android).

Bluetooth remote (Android, Chrome)

能做什么 · What it does

  • 投影片 Slides — 开始/结束放映、翻页、黑屏/白屏；看到投影上的画面、下一页、讲者备注、动画步数和计时。Start/end, next/prev, black/white; see the projector, the next slide, notes, builds and timers.
  • 音乐 Music — 控制 Spotify：播放、切歌、平滑地淡入淡出到指定音量。Spotify: play, skip, smooth fades to any level.
  • 输出 Output — 切换音响/耳机、系统音量、投影模式。Audio device, system volume, projector mode.
  • Cue — 一个按钮执行一串动作，也可以翻到某一页自动执行。One button for a sequence of steps, or automatically at a slide.
  • 开场前检查 Check — 一个画面看文件、投影机、声音、音乐、手机是否准备好。One screen showing what is ready before the event.
